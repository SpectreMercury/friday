# Friday 字母构造探索

用户持续否定之前的通用科幻符号，要求创意、线条感、JARVIS 式科技感与传播性。本轮重新从产品名称 Friday 出发，提出两种字母构造，而非恢复此前机器人脸 F 的旧约束。

## 折光 F

文件：`friday-refraction-f-v1.png`。蓝紫折线路径构成空心 F，右上珊瑚色短线作为折射回声。生成图字母辨识较直接，但整体有速度型字标气质；仍为待评价概念。

## 相位 F

文件：`friday-phase-f-v1.png`。三条青色错位路径形成连续的垂直和水平转向。线条较柔和，但实际生成更接近并行转弯线，F 中横辨识弱，不能视作已解决字母识别。

两稿均通过内置 imagegen 直接生成 PNG，未用 SVG 绘制。未替换应用图标，传播与记忆度未经过测试。
