# PWA 手机界面复核

## 当前设计依据

以用户最新提供的 GPT 手机端截图为直接视觉依据。此前 Manus 风格的标题胶囊、宋体空态和双排输入区已替换。没有使用其他产品的标志，也不宣称采用未公开的官方设计 token。

- 纯黑画布，正文直接置于黑底，控件使用深灰浮层。
- 顶栏为返回圆按钮、会话名与来源的双行文字、共用胶囊的新建和更多操作。
- 正文 16px / 26px；标题层级适度，不把紧凑理解为缩小正文。
- 输入框为单排胶囊：加号、输入、语音，有草稿时显示发送。正文左右 16px，输入框额外内收 16px；窄于 360px 时额外内收 8px。
- 默认输入框 48px 高，最多展开五行。正文独立滚动，与输入框保持 8px 间隔。
- 加号菜单统一包含文件、技能与资源、语音。更多操作仍进入独立 session 的设置。
- 回复下方提供复制、时间及适用的任务状态/操作；完成回复不再重复显示作者和完成徽章。
- 登录、设置、任务、文件、语音、确认弹窗及离线提示采用同一套黑色表面和圆角控件。

## 文本格式与安全

`message-format.js` 通过 DOM 元素与文本节点渲染段落、列表、强调、代码、有限标题和显式 HTTP(S) 链接，无 HTML 解释器和外部依赖。

原始 HTML 与图片语法保持文字，不自动下载图片；拒绝脚本/data/file/协议相对 URL 和带凭据 URL；外部链接使用 `noopener noreferrer`。格式化长度、行数及节点数设有限额，超限保留完整纯文本及换行。新脚本属于私有资源，匿名请求拒绝。

账号、session、技能版本、连接器范围、语音归属、通行密钥、Cookie、CSRF 和下载保护保留。离线仅缓存公共样式、图标和提示页，不缓存对话、业务页面、接口或文件。

## 验证

使用独立临时数据库、演示账号及软件认证器；未修改生产服务、Telegram、真实账号或连接器授权。

- Node 前端、语音与文本格式化回归共 42 项通过。
- Google Picker、浏览器认证与安全边界共 27 项通过。
- 320×568、375×667、390×844、430×932 视口：对话页横向及整体纵向溢出均为 0，正文独立滚动。
- 默认输入框实测 48px；320px 下六行草稿显示五行、内部滚动，输入区高 132px，正文仍保留 8px 间隔。
- 新建长标题会话、加号菜单、文件面板、输入后发送按钮出现、发送后草稿清空与按钮隐藏均通过浏览器检查。
- 标题截断而完整名称仍在可访问树中；浏览器无警告或错误。
- 没有触发真实麦克风、通行密钥注册、外部授权或系统剪贴板写入。iPhone 实际软键盘、Face ID、耳机和后台音频仍需真机验收。
