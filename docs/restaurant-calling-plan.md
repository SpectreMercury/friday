# 餐厅电话预订：待接入方案

状态：已检查现有实现和电话接口；尚未启用拨号，也未完成实时通话。目标地区已确定为新加坡、日本、美国、香港、英国；用户尚无电话服务账号。用户已选择全本地语音；不启用云端语音服务，电话线路账号仍未配置。不得把这份方案当作已实现能力。

## 用户流程

1. Telegram 提供餐厅或区域、餐厅当地日期时间、人数、预订姓名、可留给餐厅的联系电话，以及可接受的替代时段。
2. Pi 查询餐厅官方信息，确认分店和联系电话；缺少必要信息时一次性询问。保存用户实际授权的预订范围。
3. 如果用户已明确要求拨打该餐厅并预订，按授权执行；仅查询餐厅不触发拨号。通话使用独立电话会话，不能向现有聊天工具开放任意号码拨打。
4. 开场说明是代用户预订的 AI 助手。识别对方语言，以支持的相同语言简短交谈；不确定时询问对方偏好的语言，避免仅依据电话号码推断。
5. 遇到无位、替代时间或分店，只在用户允许范围内接受。定金、信用卡担保或新增收费条款必须带具体条件向用户询问，不能自行同意。
6. 复述日期、餐厅当地时间、人数和姓名，请餐厅明确确认；保存对应对话证据。有确认号则记录，没有则不编造。
7. Telegram 简短返回已确认、无位、未接通、待用户决定或结果待核实。电话接通/结束状态不能视为预订成功。

## 模块划分

- Pi：信息收集、官方餐厅查询、制定授权范围、提交预订请求、查询结果。
- 预订存储：用户/聊天隔离，餐厅分店、电话、当地时区、日期时间、人数、姓名、联系号码、替代方案、授权来源、状态和确认依据。
- 电话适配器：创建电话、双向音频、状态回调、挂断，持久化电话 ID；超时结果不明确时先查状态，避免重复拨号或重复预订。
- 实时会话：常驻 ASR/TTS、语音活动检测、断句、打断、输出缓冲清除、超时；不调用每句话都重新加载模型的现有 Speech.infer。
- 电话中的 Qwen：只执行预订范围内的对话动作；餐厅语音不能授权本机终端、文件读取或向第三方发送其他资料。
- 语言选择：识别结果携带语言标签；先支持 ASR、LLM 和 TTS 的共同语言集合，语言不支持时协商共同语言或报告无法继续。
- 回执：分别记录拨号状态、通话结果和预订确认依据。原始音频默认不持久保存；最小必要转写用于结果核查。

## 当前本机限制

优化前的 `local_ai/speech.py` 使用一次性 MLX 子进程，持有 GPU 锁并停止聊天引擎；旧 worker 的 TTS 固定 Chinese。当前已加入常驻与流式处理，详见 [本地语音实现与实测](local-voice-runtime.md)。已有 `runtime/speech-test/report.json` 测得一条短中文的完整合成约 32.38 秒，这不是实时首包延迟，不能当作电话实时性能指标。

需先验证常驻、多模型内存、首包延迟、断句和打断，才能选择本地实时路径。若本机延迟无法达标，再由用户决定是否采用云端实时语音，不能悄悄将语音转交新的服务。

Qwen3-TTS 官方语言：中文、英语、日语、韩语、德语、法语、俄语、葡萄牙语、西班牙语、意大利语。不能承诺任意语言自动沟通。

## 电话通道候选及验证

Twilio 提供外呼和双向 Media Streams；接入需要可用号码/账号、目的地外呼权限及服务商可访问的 HTTPS/WSS 地址。最终选择须按用户目标国家核查可用性。账号和密钥只填写本机配置，不在聊天中传递。

实施验证顺序：离线模拟（多语言、无位、替代时段、含糊确认、断线）→ 本机实时音频延迟 → 用户指定测试号码的授权通话 → 实际餐厅预订。不会因实现功能自动给餐厅打测试电话。

首选电话接入候选为 Twilio Programmable Voice + 双向 Media Streams。五个地区的官方 Voice Guidelines 均列出国际外呼可达；这并不保证某个账号、某个号码一定可拨。需配置目的地权限并做真实线路验证。

- 新加坡国内号码作为来显拨打新加坡时，需要使用 Twilio 新加坡号码；不能依赖非 Twilio 号码的 Verified Caller ID。
- 香港本地来显拨打香港目的地需使用 Twilio 号码；香港免费电话号码不能作为外呼来源。国际呼入香港固定电话的来显可能为匿名。
- 号码购买、资料要求、每分钟费率随所选号码和线路确定。先完成账号可用性检查，再决定号码，不建议先购买五个地区的号码。
- Twilio 当前试用版只允许已验证目的号码及注册国家内通话；跨国拨打真实餐厅需要升级账号并开通对应外呼权限。

本地 Qwen3-TTS 的官方 CustomVoice 声线说明不等于已验证粤语发声。香港粤语需要单独验收。若用户选择云端语音，Azure Speech 可作为候选，其文档明确列出 zh-HK 粤语识别及发声；自动语言识别与中途切换仍需单独验证配置与效果。尚未开通或调用 Azure 服务。

后续账号准备：注册 Twilio，查看账号可升级和可购语音号码情况；完成支付或资料提交由用户操作。Account SID、Auth Token 和电话号码仅保存到本机配置，不能发送到聊天。电话音频接入需 HTTPS/WSS 回调与签名验证；尚未创建公网入口。
